Svelte Rings is a web application that supports deployments across **Docker**, **Kubernetes (Helm)**, and **Vercel**.

---

## 🚀 Quick Start: Local Development

Get the application running quickly on your local machine.

### Clone & Install Dependencies

```bash
git clone [https://github.com/greenJaa/svelte-rings.git](https://github.com/greenJaa/svelte-rings.git)
cd svelte-rings
npm install
```
# Alternatively, you can use 'npm ci' for clean install based on package-lock.json
